# codesoft_Unemployment-Analysis-with-Python
TASK 2: Unemployment Analysis with Python
Project Overview
This project analyzes unemployment rate data across Indian states to understand trends, urban vs. rural disparities, and the economic impact of the Covid-19 pandemic.

Objectives
Clean and preprocess raw unemployment metrics.
Segment data to evaluate the impact of the March 2020 Covid-19 lockdown.
Identify seasonal and regional patterns in employment.
Propose actionable economic policy recommendations based on findings.
Key Findings
Lockdown Surge: Unemployment rose sharply in April–May 2020 following nationwide movement restrictions.
Urban vs. Rural Disparity: Urban areas experienced higher volatility due to service sector halts, while rural areas recovered faster aided by agricultural activities.
State-level Variations: Certain regions showed extreme vulnerability, recording peak rates well above the national average.
